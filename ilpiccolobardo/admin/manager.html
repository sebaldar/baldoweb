🤖 Provider LLM per fase

Ogni fase della pipeline può usare un provider diverso. Le fasi di scrittura creativa (genera_draft, rifinisci, similitudini) dipendono da un lungo lavoro di prompt-engineering verificato su Claude: spostarle su un altro provider senza aver prima confrontato la qualità va fatto con cautela. I controlli SI/NO sono invece buoni candidati per un provider più economico. Un provider senza API key configurata ripiega automaticamente su Claude → OpenAI al momento della chiamata.
